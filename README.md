## 📁 Meu Drive

Um projeto simples de armazenamento e gerenciamento de arquivos na web, desenvolvido com foco em uso pessoal. A proposta é simular um sistema de “drive” onde é possível organizar e acessar arquivos de forma prática.

## 🚀 Sobre o Projeto

O Meu Drive foi criado como uma solução pessoal para armazenamento e organização de arquivos, além de servir como prática no desenvolvimento web e integração com banco de dados.

Este projeto não tem foco comercial, mas sim aprendizado e uso próprio, explorando conceitos importantes como:

- Manipulação de arquivos
- Integração com banco de dados
- Estruturação de front-end
- Comunicação com APIs

## 🛠️ Tecnologias Utilizadas

As principais tecnologias e ferramentas usadas no projeto foram:

- HTML5 → Estrutura da aplicação
- CSS3 → Estilização da interface
- JavaScript → Lógica e interatividade
- Supabase → Banco de dados e backend

## 💡 Funcionalidades
- 📤 Upload de arquivos
- 📂 Organização básica de arquivos
- 🔍 Visualização dos arquivos armazenados
- ☁️ Integração com banco de dados online (Supabase)

## 📌 Objetivo

O objetivo principal deste projeto foi:

- Criar uma aplicação funcional para uso pessoal
- Praticar desenvolvimento web completo (front + backend simples)
- Entender melhor como funciona armazenamento em nuvem
